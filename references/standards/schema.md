# 标准规则卡 · 填写规范

投影相关的国标/行标/国际规范，都在这里按「一个标准一张卡」存放。**只放与投影选择、投影参数有关的条款转述**，不放整本原文。

## 目录与命名

```
references/standards/
  index.md                  # 总表，一行一个标准（唯一必须维护的索引）
  schema.md                 # 本文件
  _template.md              # 空白卡模板，复制后改名
  cn-GBT45792-2025.md       # 中国国标
  us-xxx.md / jp-xxx.md     # 其他国家
  iso-xxx.md / ogc-xxx.md   # 国际组织
  ind-dzt-xxx.md            # 行业标准（ind 后可写行业代号）
  custom-xxx.md             # 客户/单位内部惯例（没有公开标准时）
```

命名：`<国别或类别>-<标准号去空格与斜杠>.md`，全小写，例：`cn-GBT45792-2025.md`、`cn-CH-T1001-2000.md`、`us-FGDC-xxx.md`。

## 卡片结构

YAML front-matter（供以后程序化抽取）+ 五段正文。**字段可以留空写"待补"，但不要猜。**

```yaml
---
id:                       # 与文件名一致
org:                      # CN / US / JP / EU / ISO / 行业代号
std_no:                   # 标准号原样，如 GB/T 45792-2025
title:                    # 中文（或原文）名称
title_en:                 # 英文名称，没有则留空
status:                   # 现行 / 即将实施 / 作废 / 草案 / 惯例
nature:                   # 强制性国标 / 推荐性国标 / 行业强制 / 行业推荐 / 单位惯例
issued:                   # 发布日期 YYYY-MM-DD
effective:                # 实施日期
scope:                    # 一句话：管什么、管哪些区域
applies_to:               # 适用对象：专题地图 / 地形图 / 海图 / 地质图 …
inputs:                   # 判定输入，如 [比例尺, 用途, 制图区域]
source_type:              # 网页 / PDF / 纸质 / 口头惯例
source_url:               # 原始链接；没有则写"无公开链接"
source_locator:           # 条款号 + 页码，如 附录 A.1（p.12）
retrieved:                # 检索日期 YYYY-MM-DD
confidence:               # 原文转录 / 转述 / 二手引用 / 待核
---
```

正文五段（顺序固定，方便对照）：

1. `## 规则` —— **可执行部分**，表格：条件 → 投影 → 附加规定。一行一条，条件要写成能判断的形式（比例尺阈值、区域范围、用途）。
2. `## 对应的 PROJ 参考` —— 仅给参数形式（`+proj=...`），并标明哪些值是标准规定的、哪些是本卡补的默认值。
3. `## 原文摘录` —— 只摘投影相关段落，逐字引用，加 `>` 引用块。
4. `## 与本 skill 的差异` —— 三列表：差异点 / 标准怎么说 / skill 现行行为 / 是否需要人工介入。
5. `## 待核事项` —— 没确认的地方全部写在这里，不写进规则表。

## 薄卡（同族标准）

同一系列的不同分册（如 GB/T 12343.1 / .2 / .3……）若投影条款**逐字相同**，后面的分册建**薄卡**即可：

- front-matter 照填完整（标准号、日期、范围各自独立，方便精确检索）
- 正文只保留：`## 规则`（简明表）+ `## 与第 N 部分的关系`（差异对照）+ `## 原文摘录`（证明确实相同）+ `## 待核事项`
- 顶部用一句话写明"薄卡：条款与第 1 部分完全相同，仅比例尺不同"，并给出主卡链接

## 填写原则

- **只摘投影**：一本标准里投影可能只有一节，其余章节不要。
- **不复制原文**：整页截图、整本 PDF 不放进 skill（体积 + 版权）；需要留证的，摘录关键段落文字即可。
- **只有网址也能成卡**：`source_type: 网页`、`source_locator: 章节标题`、`confidence: 转述`，内容照样能填。
- **规则与出处分离**：`## 规则` 是给程序/人执行的，`## 原文摘录` + front-matter 是给出处复核的。两者不要混。
- **不确定标 `待核`**：宁可空着，也不要按惯例"合理推断"后写成标准要求。

## 以后接入页面的方式（暂不实现）

页面里的「标准模式」只需要每张卡 `## 规则` 那几行：把条件列翻译成
`{ minScale, maxScale, requirement: "方位/面积", proj: "tmerc|lcc|aea", zone: 3|6 }`
即可拼成一张几十行的映射表嵌进 HTML，卡片本身仍留在 references 里当知识库。
