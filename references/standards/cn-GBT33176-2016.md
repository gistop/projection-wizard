# GB/T 33176-2016 国家基本比例尺地图 1:500 1:1000 1:2000 地形图 —— 投影条款

> 2016-10-13 发布，2017-05-01 实施；推荐性国家标准；自然资源部（测绘地理）归口。是 1:500～1:2 000 图种的**产品级**规定，投影框架与强制性国标 GB 35650-2017 一致，但把「3° 带起算点」和「独立坐标系」写到了可执行的粒度。

## 规则

| # | 条件 | 投影 | 参数规定 |
|---|---|---|---|
| R1 | 1:500 / 1:1 000 / 1:2 000（统一） | **高斯-克吕格投影** | **按经差 3° 分带，从东经 1°30′ 起算**（带界 1.5°E，中央经线 3°、6°、9°…，即 λ₀ = 3n） |
| R2 | 确有必要时 | **独立坐标系**（须依法批准） | 中央子午线**可采用任意经线**；投影面可采用**当地平均高程面**或**黄海平均海平面** |

质量约束：

- **投影长度变形值不应大于 25 mm/km**（= 2.5×10⁻⁵，约 1/40 000）

## 对应的 PROJ 参考（仅参数形式，非标准原文）

```
# R1 3° 带：带号 n = λ₀ / 3（例：n=39 → λ₀=117°E；带号前置时 x_0 = 39500000）
+proj=tmerc +lat_0=0 +lon_0=117 +k=1 +x_0=39500000 +y_0=0 +ellps=GRS80 +units=m +no_defs

# R2 独立坐标系：任意中央经线 + 抬高投影面（用 k 抵偿，避免改椭球）
# k = 1 + H / R（H = 投影面高程，R ≈ 6 371 000 m）；H=100m → k≈1.0000157
+proj=tmerc +lat_0=0 +lon_0=<任意> +k=1.0000157 +x_0=500000 +y_0=0 +ellps=GRS80 +units=m
```

> 说明：`k=1`、带号前置、`k=1+H/R` 的换算属于通行做法与**本卡补充**；标准原文只规定分带起算点、独立坐标系的允许范围与变形限值。

## 原文摘录

> 5.1.1.4 投影采用高斯-克吕格投影，从东经 1°30′起算，按经差 3°分带；确有必要时，可采用依法批准的独立坐标系，中央子午线可采用任意经线，投影面可采用当地平均高程面或黄海平均海平面。投影长度变形值不应大于 25 mm/km。

## 与本 skill（几何启发式）的差异

| 差异点 | 本标准 | skill 现行行为 | 需要人工介入 |
|---|---|---|---|
| 判定入口 | 图种（比例尺）固定 | 无比例尺概念，按经纬跨度 | 必须 |
| 比例因子 | 高斯投影 k = 1（变形靠分带与投影面抵偿控制） | 经度跨度 ≤6° 时给仿 UTM `k₀=0.9996` | 必须改 k |
| 分带起算 | 3° 带自 1.5°E 起算，λ₀ = 3n | 无带号/分带概念 | 必须 |
| 独立坐标系 | 允许任意中央经线 + 当地平均高程面/黄海平均海面 | **完全不支持**（只有标准 bbox 中心经线） | 必须手工构造 PROJ |
| 变形限值 | ≤ 25 mm/km | 不校验 | 出图时核算 |

## 待核事项

1. **条款上下文**：5.1.1 整节（是否还有分幅、图幅编号、坐标单位等关联规定）与页码待补。
2. **带号是否前置**：标准未在此条写明；与 GB 35650-2017 的同类问题一致，需按具体成果/编图规定确认。
3. **同系列其他图种**：1:5 000、1:1 万 等对应图种的产品标准（编号未确认）尚未收录。
4. **投影面抵偿的实现方式**：标准只说"投影面可采用当地平均高程面"，实际有用 `+k`、也有改椭球长半轴的两种做法，孰为合规需按地方规定确认。
