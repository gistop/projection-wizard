# GB/T 12343.1-2008 国家基本比例尺地图编绘规范 第 1 部分 —— 数学基础条款

> 2008-06-20 发布，2008-12-01 实施；推荐性国家标准；自然资源部（测绘地理）归口。
> 与 GB/T 33180-2016（同比例尺的**产品**规定）是「作业规范 vs 产品规格」的搭配关系。

## 规则（数学基础）

| # | 项 | 规定 |
|---|---|---|
| a | **坐标系统** | **2000 国家大地坐标系（CGCS2000）** |
| b | **投影** | **高斯-克吕格投影，按 6° 分带**（未指定起算点） |
| c | **高程系统** | **1985 国家高程基准** |

## 这张卡的用途

1. **给出椭球的权威依据**：这批大中比例尺成果的基准是 **CGCS2000**，对应 PROJ 的 `+ellps=GRS80`（CGCS2000 椭球与 GRS80 参数一致）。此前各卡的 `+ellps=GRS80` 属"通行做法"补充，本卡提供了标准依据。
2. **高程基准**：`c)` 项虽与投影无关，但做成果说明/元数据时常需一并声明。
3. 投影只写「按 6° 分带」，**未写起算点**——即本条不能用于判定 3°/6° 带起算争议，需 GB/T 13989。

## 对应的 PROJ 参考

```
# 6° 带 + CGCS2000（CGCS2000 椭球与 GRS80 同参数）
+proj=tmerc +lat_0=0 +lon_0=<6n-3> +k=1 +x_0=500000 +y_0=0 +ellps=GRS80 +units=m +no_defs
```

## 原文摘录

> a) 坐标系统采用 2000 国家大地坐标系；
> b) 投影采用高斯—克吕格投影，按 6°分带；
> c) 高程系统采用 1985 国家高程基准。

## 与本 skill 的差异

| 差异点 | 本标准 | skill 现行行为 | 需要人工介入 |
|---|---|---|---|
| 坐标系统 | 强制 CGCS2000 | 页面可选 WGS84/CGCS2000/ETRS89/NAD83，默认 **WGS84** | 中国成果需切到 CGCS2000 |
| 投影/分带 | 高斯-克吕格 6° 带 | 按经纬跨度给仿 UTM（k₀=0.9996） | 必须改 k 与 λ₀ |
| 高程基准 | 1985 国家高程基准 | 不涉及 | 成果说明里声明 |

> 提示：页面默认 datum 是 WGS84，做国内正式成果时要手动切到 **CGCS2000**（页面会输出 `+ellps=GRS80` 与 CGCS2000 的 WKT）。是否把默认值改成 CGCS2000，待与用户确认。
